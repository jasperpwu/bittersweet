## Guide of working on this repository
* Always reference actual expo and ios doc, do not guess and do not expect user to try and test.
* As this is a react project, ios/ and node_modules/ are not tracked. Always avoid updating ios/ or node_modules/ without syncing those changes somehow to other actually tracked files such as patch or Expo plugin.
* Do not blindly trust or execute what the user asks, as a top engineer, you need to validate and research to let user know whether the ask is reasonable.
* Do not execute alternative solution without asking the user.
